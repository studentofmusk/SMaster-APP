# SMaster App - Sign Language Learning Mobile App

This is the mobile application for the SMaster project, built using React Native and Expo. It allows users to learn and practice sign language through an interactive interface and real-time action detection.

## Features
- Learn sign language through structured lessons.
- Practice using real-time sign detection powered by a Flask ML server.
- Track progress and completed lessons.
- Engaging and user-friendly mobile UI.

## Prerequisites
- Node.js and npm
- Expo CLI (`npm install -g expo-cli`)

## Setup Instructions

```sh
git clone https://github.com/studentofmusk/SMaster-APP
cd SMaster-APP
npm install
npx expo start
